Chapter 1b — Neoclassical Growth Model

The Ramsey Model

Endogenous saving, instantaneous utility, the Hamiltonian, and optimal consumption dynamics.

Motivation

Why an Endogenous Saving Rate?

In the Solow model, the saving rate $s$ is assumed to be constant and exogenous. While this provides a tractable benchmark, it has two major limitations:

1. Empirical variation: There is no reason why the saving rate in an economy should be constant. It can vary significantly with the level of economic development and demographic transitions.
2. Microeconomic foundation: In an economic model, one would prefer to have an endogenous saving rate as the consumption–saving trade-off is an economic decision. Forward-looking households choose how much to consume today versus how much to save for future generations.
The Ramsey approach: Instead of imposing an arbitrary $s$, the Ramsey model lets households choose their optimal path of consumption over time by maximising an intertemporal utility function.
Part 1 / 3

Instantaneous Utility Function $u(c)$

We need a household instantaneous utility function $u(c)$ where $c$ is consumption per effective worker:

$$c = \frac{C}{AL}$$

The instantaneous utility function $u(c)$ satisfies four standard neoclassical characteristics:

$u'(c) > 0$

Positive marginal utility: Marginal utility is positive (more consumption = a higher utility).

$u''(c) < 0$

Decreasing marginal utility: Marginal utility is decreasing (preference for consumption smoothing across time).

$\lim_{c \to 0} u'(c) = \infty$

Inada condition at 0: The marginal utility of the first unit of consumption is infinite. Households will never choose zero consumption.

$\lim_{c \to \infty} u'(c) = 0$

Inada condition at $\infty$: As consumption becomes arbitrarily large, marginal satisfaction approaches zero (asymptotic satiation).

The instantaneous utility function $u(c)$ is strictly increasing ($u' > 0$) and strictly concave ($u'' < 0$).
Part 2 / 3

Intertemporal Utility & Model Setup

Households are forward-looking and maximise their total discounted future utility over an infinite horizon:

$$W = \int_0^\infty u(c(t))\,e^{-\rho t}\,dt$$
$c(t) = \dfrac{C}{AL}$ — consumption per effective worker at time $t$
$\rho > 0$ — annual discount rate for (future) utility (pure rate of time preference)
$e^{-\rho t}$ — discount factor: utility in the distant future is discounted more heavily because households prefer present consumption.

Other equations of the model (same as in the Solow model)

1. Production function:
$$Y = (AL)^{1-\alpha}K^\alpha$$
In intensive form: $\bar{y} = \dfrac{Y}{AL} = f(k) = k^\alpha$.
2. Aggregate capital accumulation:
$$\frac{dK}{dt} = Y - \delta K - C$$
Gross investment is output minus consumption ($I = Y - C$), and net capital accumulation is gross investment minus physical depreciation.
3. No-Ponzi game condition:

Households cannot run an infinite debt scheme (Ponzi scheme) by continuously borrowing to finance consumption without ever repaying.

1
Write $k = \dfrac{K}{AL}$ and differentiate with respect to time: $$\frac{dk}{dt} = \frac{1}{AL}\frac{dK}{dt} - k\,\frac{\frac{d(AL)}{dt}}{AL}$$
2
Growth of effective labour $AL$: Since $\dfrac{1}{A}\dfrac{dA}{dt} = g$ and $\dfrac{1}{L}\dfrac{dL}{dt} = n$: $$\frac{\frac{d(AL)}{dt}}{AL} = n + g$$
3
Substitute $\dfrac{dK}{dt} = Y - \delta K - C$: $$\frac{dk}{dt} = \frac{Y - \delta K - C}{AL} - (n + g)k = \frac{Y}{AL} - \delta k - \frac{C}{AL} - (n + g)k$$

Using $f(k) = \dfrac{Y}{AL}$ and $c = \dfrac{C}{AL}$:

$$\boxed{\frac{dk}{dt} = f(k) - (n + \delta + g)k - c}$$
Part 3 / 3

Solving the Ramsey Model (1/3) — The Hamiltonian

The household intertemporal maximisation program is:

$$\max_c \quad W = \int_0^\infty u(c(t))\,e^{-\rho t}\,dt \qquad \text{under: } \frac{dk}{dt} = f(k) - (n + \delta + g)k - c$$

The Hamiltonian

$$\mathcal{H} = u(c) + \lambda\left[f(k) - (n + \delta + g)k - c\right]$$

where $\lambda(t)$ is the co-state variable: the shadow price of capital per effective worker.

First-Order Conditions & Transversality Condition

1
First-order condition on $c$: $\dfrac{\partial \mathcal{H}}{\partial c} = 0$
$$\frac{\partial \mathcal{H}}{\partial c} = 0 \implies \boxed{u'(c) = \lambda}$$

The marginal utility of consumption must equal the shadow price of capital at all times.

2
First-order condition on $k$ (co-state equation): $\dfrac{d\lambda}{dt} = \rho\lambda - \dfrac{\partial \mathcal{H}}{\partial k}$
$$\rho\lambda = \lambda\left[f'(k) - (n + g + \delta)\right] + \frac{d\lambda}{dt}$$

Governs the rate at which the shadow value of capital $\lambda$ changes over time.

3
The Transversality Condition:
$$\lim_{t \to \infty} e^{-\rho t}\,\lambda(t)\,k(t) = 0$$

The present value of capital at infinity must be zero (households must not leave valuable capital unconsumed at the end of time).

Part 2 / 3

Solving the Ramsey Model (2/3) — The Euler Equation

Combining the first two conditions yields the Euler equation:

$$\boxed{\frac{u''(c)}{u'(c)}\frac{dc}{dt} = \rho - \left[f'(k) - (n + g + \delta)\right]}$$
1
Differentiate $u'(c) = \lambda$ with respect to time $t$: $$\frac{d\lambda}{dt} = u''(c)\frac{dc}{dt}$$
2
Substitute $\frac{d\lambda}{dt}$ into the co-state equation: $$\rho\lambda = \lambda\left[f'(k) - (n + g + \delta)\right] + u''(c)\frac{dc}{dt}$$
3
Divide both sides by $\lambda = u'(c)$: $$\rho = f'(k) - (n + g + \delta) + \frac{u''(c)}{u'(c)}\frac{dc}{dt}$$

Rearranging yields the Euler equation:

$$\boxed{\frac{u''(c)}{u'(c)}\frac{dc}{dt} = \rho - \left[f'(k) - (n + g + \delta)\right]}$$
Economic Meaning: This is the Euler equation. It gives the optimal growth rate of consumption.

• The net marginal product of capital $f'(k) - (n + g + \delta)$ is the reward for waiting (saving).
• $\rho$ is the psychological cost of waiting (impatience).
• When $f'(k) - (n + g + \delta) > \rho$, the reward exceeds impatience, so consumption rises over time ($\frac{dc}{dt} > 0$).

The Ramsey Steady State / Regular Path

When $f'(k) = \rho + n + g + \delta$, we have:

$$\frac{u''(c)}{u'(c)}\underbrace{\frac{dc}{dt}}_{=0} = 0 \iff \boxed{f'(k^*) = \rho + n + g + \delta}$$

And this is the steady state / regular path.

The result is very similar to that of the Solow model, except for the parameter $\rho$ (the discount rate).

Summary

Solving the Ramsey Model (3/3) — The Optimal Dynamic System

The complete dynamic system describing the economy at the optimum consists of:

1. Optimal Consumption Growth (Euler Equation):
$$\frac{u''(c)}{u'(c)}\frac{dc}{dt} = \rho - \left[f'(k) - (n + g + \delta)\right]$$
2. Capital Accumulation (Resource Constraint):
$$\frac{dk}{dt} = f(k) - (n + g + \delta)k - c$$
3. Transversality Condition (Terminal Constraint):
$$\lim_{t \to \infty} e^{-\rho t}\,\lambda(t)\,k(t) = 0$$
Ramsey Steady State vs. Solow Golden Rule:

• Solow Golden Rule: $f'(k^{**}) = n + g + \delta$
• Ramsey Steady State: $f'(k^*) = \rho + n + g + \delta$

Since households discount the future ($\rho > 0$), we have $f'(k^*) > f'(k^{**})$. Because capital exhibits diminishing returns ($f'' < 0$), this implies:

$$\boxed{k^* < k^{**}}$$

Dynamic Efficiency: In the Solow model, over-saving ($s > \alpha$) could push the economy into dynamic inefficiency ($k^* > k^{**}$). In the Ramsey model, forward-looking households will never accumulate capital beyond the Golden Rule level: $k^*$ is strictly below $k^{**}$, ruling out dynamic inefficiency endogenously.

Synthesis: Solow Model vs. Ramsey Model

Feature Solow Model (Chapter 1a) Ramsey Model (Chapter 1b)
Saving Rate Exogenous and constant ($s$) Endogenous, chosen by households ($s(t)$)
Household Behaviour Mechanical saving rule ($S = sY$) Intertemporal utility maximisation ($\max W$)
Steady-State Condition $s f(k^*) = (n + g + \delta)k^*$ $f'(k^*) = \rho + n + g + \delta$
Dynamic Inefficiency Possible if $s > \alpha$ ($k^* > k^{**}$) Impossible ($k^* < k^{**}$ always because $\rho > 0$)
